# Repository Maintenance

The GitHub repository keeps application source, required interface assets, tests, model data, and development tools.

Old root-level research papers, slides, desktop shortcuts, the starter HTML demo, and document/presentation generation scripts have been removed from Git tracking. Their local files are preserved. Git history also retains previously committed versions.

Local competition submissions, rendered pages, screenshots, videos, temporary dependencies, audit runs, generated interface files, and output directories are ignored. This keeps local work out of accidental commits.

No app behavior, fitted model parameters, or scientific results were changed by this cleanup. No deployment is part of the cleanup.

## November 24, 2026

The repository now includes the existing newer login template, page-navigation helper, styles, logo, login test, and separate Hosting configuration that the local build already used. The README points to the verified current public site at https://vaultlab.web.app/ and includes screenshots from that site.

An MIT License, upstream attribution notice, contribution notes, build/test workflow, and certificate-preparation checklist were added. Local research environments, final-submission packages, and unrelated production scripts stay on disk but are excluded from GitHub. No research results were replaced, no raw videos were published, and no Hackatime hours or certificate status are claimed.
